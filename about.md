# Propaganda Dash
A simple mod that gives you some "useful" tips while playing, have fun! :)

*NOTE: This mod uses an LLM to have the ability to give the "tips", so just beware that it could mess up or break at some points!*
**This is a concept currently and I'm not sure if I'll continue this mod! (So dont expect much more from this mod)**
